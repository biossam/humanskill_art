# 공공미술교육연구회 (biossam_art_class)

공공미술교육연구회 미술 교재들의 수업 영상과 선생님 자료를 제공하는 웹사이트입니다. 교재마다 맨 위 탭으로 나뉩니다.

| 교재 | 개발 | 학년 | 차시 |
|---|---|---|---|
| 휴먼스킬아트 | 장혜림 | 6학년 | 6 |
| 우리 옛 그림 산책 | 최빛나 | 5학년 | 7 |
| 지역 미술 여행(공공미술) | 장현주 | 3학년 | 6 |
| 우리가 만드는 공간 디자인 | 이은찬 | 6학년 | 7 |
| 같은 세상, 다른 눈 렌즈로 담아내는 나의 세상 | 노기현 | 4학년 | 7 |
| 색, 이런 느낌 저런 느낌 | 김예나 | 4학년 | 7 |

2025 자료(맨 위 연도 버튼): **누구나 예술가가 될 수 있다**(선생님 자료, 학생용 화면에는 숨김), **어느 날 눈떠보니 예술가가 되었다**(7~10차시, 파트별 영상·활동).

- 선생님 자료실: https://biossam.github.io/humanskill_art/
- 학생용 화면: https://biossam.github.io/humanskill_art/?view=student

## 무엇이 있나

| 화면 | 내용 |
|---|---|
| 첫 화면 | 교재 소개, 6개 차시 목록 (판단 → 발견 → 해석 → 재구성 → 소통 → 성찰) |
| 차시 화면 | 수업 영상, 학습 목표, 준비물, 활동 순서, 생각해 볼 질문, 선생님 자료(활동지) |
| 수업 모드 | 교실 TV용 전체 화면. 화살표·리모컨으로 활동 단계를 한 단계씩 넘김 |
| 학생용 화면 | 주소 끝 `?view=student`. 선생님 자료 칸이 숨겨짐 |
| QR 코드 | 학생용 화면으로 가는 QR 코드. 인쇄 가능 |

## 자료 추가

모든 내용은 `data/course.json`에서 관리합니다. 방법은 [docs/자료추가방법.md](docs/자료추가방법.md)를 보세요.

- 영상: YouTube(직접 찍은 영상은 일부공개)에 올리고 영상 ID만 기록
- 활동지: `files/차시번호/worksheet.hwpx`에 넣거나, 구글 드라이브 공유 링크를 기록
- 수업 PPT와 지도안은 저작권 검토에 따라 공개 사이트에 올리지 않습니다(작가 작품 이미지, 전시 사진, 디자인 소재 포함). 수업 지도안과 PPT는 [경기형 AI 교수·학습 플랫폼](https://hi.goe.go.kr/contentlibrary/recommended)에서 받을 수 있습니다.

## 구조

```
index.html              화면 틀
assets/css/style.css    디자인
assets/js/app.js        동작 (차시 목록, 차시 화면, 수업 모드, QR)
data/site.json          ★ 사이트 이름, 교재(탭) 목록
data/course.json        ★ 휴먼스킬아트 차시·영상·자료 링크
data/courses/*.json     ★ 다른 교재들
docs/자료추가방법.md     자료 추가 안내
```

빌드 과정이 없는 정적 사이트이며 GitHub Pages로 무료 운영합니다.

## 내 컴퓨터에서 미리 보기

`data/course.json`을 불러오므로 파일을 더블클릭하면 열리지 않습니다. 폴더에서 아래 명령을 실행한 뒤 http://localhost:8000 에 접속하세요.

```
python -m http.server 8000
```

# 자료 추가 방법

사이트의 모든 내용은 `data/course.json` 한 파일에 들어 있습니다.
GitHub 저장소에서 이 파일을 열고 연필(편집) 아이콘을 눌러 고친 뒤 **Commit changes**를 누르면 1~2분 뒤 사이트에 반영됩니다.

## 차시 한 개의 모양

```json
{
  "no": 1,
  "title": "예술가의 판단",
  "goal": "학습 목표 한 줄",
  "materials": ["준비물1", "준비물2"],
  "steps": ["활동 1단계", "활동 2단계", "활동 3단계"],
  "questions": ["생각해 볼 질문 1", "생각해 볼 질문 2"],
  "videos": [],
  "teacher": { "worksheet": "" }
}
```

비워 둔 칸은 화면에 나오지 않거나 "준비 중"으로 표시됩니다.

## 1. 영상 넣기

### 직접 찍은 영상

1. YouTube에 **일부공개**로 올립니다. (아동용으로 설정해도 사이트에서 재생됩니다.)
2. 영상 주소에서 ID를 복사합니다.
   - `https://www.youtube.com/watch?v=abcDEF12345` → `abcDEF12345`
   - `https://youtu.be/abcDEF12345` → `abcDEF12345`
3. `videos` 안에 넣습니다.

```json
"videos": [
  { "youtubeId": "abcDEF12345", "title": "시범 영상" }
]
```

### 다른 사람이 만든 유튜브 영상

`external`, `channel`, `url`을 함께 적으면 화면에 출처가 자동으로 표시됩니다.

```json
{ "youtubeId": "xyz98765432", "title": "작품 감상", "external": true,
  "channel": "채널 이름", "url": "https://www.youtube.com/watch?v=xyz98765432" }
```

영상이 여러 개면 쉼표로 이어 적습니다. 첫 번째 영상이 수업 모드에서 재생됩니다.

### 배지 모으기 (학생용 화면)

학생용 화면에서 차시의 "배지 영상" 하나를 실제로 70% 이상 보면 그 차시 배지를 받습니다(앞으로 건너뛴 구간은 세지 않음). 학생 화면에는 이 기준을 표시하지 않습니다. `"short": true`를 적은 숏츠가 있으면 그 영상이 배지 영상이고, 없으면 그 차시의 영상 중 아무거나 하나를 70% 이상 보면 됩니다. 기록은 학생 기기의 브라우저에만 남고(이름·로그인 없음), 맨 위 **내 배지**에서 모은 배지를 볼 수 있습니다.

```json
{ "youtubeId": "ZOWcQH3vgkg", "title": "조형 요소와 원리", "short": true }
```

## 2. 수업 활동지 넣기

> 수업 PPT와 지도안은 작가 작품 이미지, 전시 사진, 디자인 소재가 들어 있어 공개 사이트에 올리지 않습니다. 대신 차시 화면의 선생님 자료 칸에서 [경기형 AI 교수·학습 플랫폼](https://hi.goe.go.kr/contentlibrary/recommended)으로 안내합니다. 안내 주소는 `data/course.json`의 `materials`에서 바꿀 수 있습니다.

활동지는 `files/차시번호/worksheet.hwpx`로 저장소에 넣거나, 아래처럼 구글 드라이브에 올려 링크를 적습니다. 올리기 전에 작품 사진, 학생 얼굴, 다른 사람이 만든 그림 소재가 없는지 확인하세요.

1. 구글 드라이브에 파일을 올립니다.
2. 파일을 오른쪽 클릭 → **공유** → 일반 액세스를 **링크가 있는 모든 사용자 / 뷰어**로 바꿉니다.
3. **링크 복사**를 눌러 아래 칸에 붙여 넣습니다.

```json
"teacher": {
  "worksheet": "https://drive.google.com/file/d/…/view"
}
```

파일을 고칠 때는 드라이브에서 **관리 → 버전 관리 → 새 버전 업로드**를 쓰면 링크가 그대로 유지되어 사이트를 고칠 필요가 없습니다.

## 3. 주의할 점

- 따옴표(`"`)와 쉼표(`,`)를 빠뜨리지 마세요. 목록의 마지막 항목 뒤에는 쉼표가 없어야 합니다.
- 고친 뒤 사이트가 "수업 목록을 불러오지 못했어요"라고 나오면 쉼표나 따옴표가 빠진 것입니다. 저장소의 **History**에서 이전 버전으로 되돌릴 수 있습니다.
- 학생 얼굴과 이름이 나오는 영상은 올리지 않습니다. 작품 사진은 이름을 가린 뒤 사용합니다.

## 4. 학생용 화면과 QR 코드

- 학생용 화면 주소: `https://biossam.github.io/humanskill_art/?view=student` (선생님 자료 칸이 숨겨집니다)
- 선생님 화면 첫 페이지의 **학생에게 나눠 줄 QR 코드**에서 QR 코드를 띄우거나 인쇄할 수 있습니다.

## 5. 교재(탭) 추가

- 맨 위 탭은 `data/site.json`의 `courses` 순서(학년순, 휴먼스킬아트는 마지막)대로 나옵니다. 주소에 교재가 없으면 `site.default` 교재(휴먼스킬아트)가 열립니다. `tab`을 적으면 탭에는 그 짧은 이름이 나옵니다.
- 교재마다 내용 파일이 따로 있습니다. 휴먼스킬아트는 `data/course.json`, 나머지는 `data/courses/교재id.json`입니다. 차시 모양은 위와 같습니다.
- 교재 주소: `https://biossam.github.io/humanskill_art/#/c/교재id` (학생용은 `?view=student#/c/교재id`). 교재마다 학생용 QR 코드가 따로 만들어집니다.
- 교재마다 `year`(2025, 2026)를 적으면 맨 위 연도 버튼으로 나뉩니다. `"teacherOnly": true`인 교재는 학생용 화면에 나오지 않습니다.
- 차시 없이 링크만 모은 선생님 자료는 교재 파일의 `course.resources`에 `{ "title", "author", "source", "url" }`로 적습니다(예: `data/courses/gongmitalk.json`).
- 한 교재 안에 단원을 더 넣으려면 그 파일의 `units` 목록에 같은 모양으로 추가합니다.

## 수업 시연 PDF (맨 위 '수업 시연' 탭)

1. PDF를 `files/demo/` 폴더에 `1.pdf`, `2.pdf` … `40.pdf` 이름으로 올립니다.
2. `data/courses/demo.json`에서 해당 차시의 `"url": ""`을 `"url": "files/demo/1.pdf"`처럼 바꾸고, `"source"`를 `"PDF"`로 바꿉니다.
3. 차시 제목을 바꾸려면 `"title"`을 고칩니다.

## 사이트 고친 뒤 옛 화면이 보일 때
`index.html`의 `style.css?v=…`, `app.js?v=…` 숫자를 바꾸면 모든 선생님 브라우저가 새 파일을 받아요.
